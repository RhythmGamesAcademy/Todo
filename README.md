# ひとつずつ。

やることと、その続き。TODOと進捗メモを管理する日本語のWebアプリです。

## 開発

Node.js 22.12以降（推奨: Node.js 24）を使用してください。

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開きます。

```sh
npm test
npm run build
npm run preview
```

## 機能

- TODOの作成・編集・削除と、削除直後の取り消し
- 期限日時（任意）、優先度（高・中・低）、状態（未着手・進行中・完了）
- 期限なしの新規作成、または期限ありから期限なしに変更する際の確認
- カードから開く詳細モーダルと、日時付き進捗メモの追加・編集・削除
- 期限順／優先度順、状態・今日の期限での絞り込み、タイトル・説明・メモ検索
- 現在の日時を毎秒表示
- Googleカレンダーの予定作成画面へのリンク（締切から15分間）
- JSONバックアップの書き出し・復元
- レスポンシブ画面、キーボード操作、フォーカス表示、入力破棄・削除の確認

## 保存と日時

TODOとメモは、このサイトを開いたブラウザのlocalStorageに保存します。ログイン、利用者間の共有、端末間の自動同期はありません。同じ端末でもブラウザやブラウザプロファイルが違えば別のデータです。サイトデータを削除すると消えるため、必要に応じてバックアップを利用してください。URLのドメイン・プロトコル・ポートが変わると保存領域も変わります。

保存失敗時は成功表示をせず、入力を残してエラーを表示します。読み込めない保存データは自動で上書きせず、元データの書き出しと復元・初期化を案内します。

期限は利用者の端末のタイムゾーンで入力・表示し、保存時はISO 8601形式にします。期限順では期限なしを末尾に置き、同じ期限なら優先度順にします。優先度順では同じ優先度内を期限順にします。今日の期限には未完了のTODOのみ表示します。

## Googleカレンダー

APIキーやアプリ内のGoogle認証は不要です。「Googleカレンダーに追加」で入力済みの予定作成画面を別タブに開きます。利用者がGoogleアカウントでログインし、保存します。タイトルは「【締切】TODOタイトル」、開始は締切時刻、終了は15分後です。進捗メモは送信せず、TODOの説明を予定の説明に含めます。

保存したかどうかの検出、重複登録の防止、期限変更後の同期は行いません。期限なしの場合は、代わりに期限の設定を案内します。

## Vercelへの公開

1. このプロジェクトをGitHubリポジトリへpushします。
2. VercelでそのリポジトリをImportします。
3. Framework PresetはVite、Build Commandは npm run build、Output Directoryは dist を指定します。
4. Deployします。環境変数・データベースは不要です。

Hobbyプランは非商用の個人利用向けで、無料枠の上限があります。サービスの最新条件は公開時に確認してください。

## GitHub Pagesへの公開

同梱の .github/workflows/pages.yml がビルド・公開します。

1. 公開リポジトリへpushします。
2. Settings → Pages → Build and deployment → SourceでGitHub Actionsを選びます。
3. mainブランチへのpush、またはActionsから手動でワークフローを実行します。

Viteのbaseを相対パスにしているため、リポジトリ配下でも動作します。ルーティングは単一ページ内で完結し、サーバーのリライト設定は不要です。

## 技術構成

React / TypeScript / Vite / Tailwind CSS / Lucide React / Vitest。

- src/App.tsx: 一覧・状態管理・確認・バックアップ
- src/ui.tsx: モーダル・カード・フォーム・メモ
- src/model.ts: 型・日時・並べ替え・検索・カレンダーURL・保存形式の検証
- src/storage.ts: localStorageの読み書き
- src/model.test.ts: 並べ替え・期限・検索・カレンダー・バックアップのテスト
- src/App.test.tsx: 作成・メモの永続化・入力保護・保存失敗などの操作テスト（jsdom）
- src/index.css: Tailwindと画面スタイル
